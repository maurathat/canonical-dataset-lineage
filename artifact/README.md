# Artifact: Canonical Dataset Lineage for Decentralized Agent Networks

This artifact reproduces Table II of the paper. It implements the `dataset.v1` canonicalization pipeline from Town proposal v0.3 §1: admission and validation, NFC folding, the closed payload shape, parent normalization, exclusion, and CPB `jcs`. It does **not** implement signing, lineage traversal, freshness, or the Town plugin.

## Files

| File | Purpose |
|---|---|
| `canon.py` | The pipeline. `dataset_id(raw: bytes)` returns a 64-character lowercase hex identifier or raises `Reject(reason)`. |
| `vectors.json` | 47 vectors. Each gives its input as exact bytes (base64) with its pinned outcome, which is either an identifier or a typed reason code. |
| `build_vectors.py` | Regenerates `vectors.json`. |
| `run.py` | Checks every vector, enforces the pinned Town commit and `records.py` digest, compares re-encodings with Town's `records.fingerprint` (the control), and prints Table II and a runtime receipt. It exits 1 on any mismatch. |
| `results.txt` | The recorded run. |
| `requirements.txt` | Fully pinned dependencies. |
| `table1.py` | Regenerates Table I of the paper: four encodings of one dataset value, three digest recipes. |
| `table1-results.txt` | The recorded Table I run, measured against Town's `records.fingerprint`. |

`SHA256SUMS` covers every file in this directory except itself.

## Run

```
git clone https://github.com/projnanda/nandatown
git -C nandatown checkout df0b5f1fd0c2ec2f9535c786fcf83694096e4e9f
pip install -r requirements.txt
TOWN_SRC=nandatown/src python3 run.py
```

Without `TOWN_SRC`, the runner checks the vectors but skips the control comparison.

### Table I

    TOWN_SRC=<nandatown>/src python3 table1.py    # fingerprint column measured on Town
    python3 table1.py                             # fingerprint column computed locally

Reproduces the four encodings and three digest recipes in Table I of the paper.
Recorded output: `table1-results.txt`. Town's `records.fingerprint()` returns
`sha256:<hex>`; the algorithm label is stripped for display and the digest is
unchanged. The local fallback is digest-equivalent to Town's serializer at the
pinned commit, so Table I reproduces without a Town checkout.

## Provenance of the expected values

The pinned identifiers were generated by this implementation. They catch regressions and give independent implementations a fixed target, but they are not independent evidence. The recorded run used CPython 3.13.3 with Unicode 15.1.0 and the dependency versions listed in `requirements.txt`. No independent implementation has yet reproduced this revision.
